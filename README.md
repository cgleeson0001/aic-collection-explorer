# AIC Collection Explorer

A web app that lets you search and explore artwork from the 
Art Institute of Chicago's public collection.

## API Used
Art Institute of Chicago API  
Documentation: https://api.artic.edu/docs

## Endpoints Used
- Search artworks: /artworks/search
- Artwork detail: /artworks/{id}

## How to Run
1. Clone this repository
2. Open index.html in your browser
3. Type a search term and explore

## Features
- Search artworks by keyword
- View full artwork details including image, artist, date, and medium
- Error handling for empty searches and missing images
